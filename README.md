# Lyricker（Web 版）

歌詞の元の内容と編集中の内容を見比べながら、AI の力も借りて推敲するためのノートです。
ブラウザで動くので、Windows・Mac・iPhone・iPad のどれでも同じように使えます。

## 使い方

1. 左のノート（元の歌詞）に歌詞を貼り付けます。右のノートにも同じ内容が読み込まれます。
   - スマートフォンは枠を長押しして「ペースト」、または「貼り付け」ボタン
2. 右のノートで編集します。左と比べて
   - ✓（緑）変更した行 / ＋（緑）追加した行 … 右のノートの行頭
   - −（赤）右で削除した行 … 左のノートの行頭
   - 右のノートで同じ行が 2 回以上出てくる行は橙色（`[サビ]` のように `[ ]` で囲んだ部分は判定しません）
3. 仕上がったら「全文コピー」で右のノートの全文をコピーして、Suno などに貼り付けます。
4. 次の歌詞に移るときは「クリア」（確認のあと左右とも消えます）。

そのほか

- 「行を戻す」… カーソル行（選択していれば選択した行）を元の歌詞に戻す。直前で削除した行も戻る
- 「全体を戻す」… 右のノートを元の歌詞に戻す（どちらも Ctrl+Z で取り消せます）
- 右のノートの文字をダブルクリックすると、その 1 文字を目印として赤く反転表示（もう一度で解除）
- ▲▼（F3 / Shift+F3）で前後の差異へ移動、A− / A＋ で文字の大きさ
- 作業中の内容はブラウザの中に自動で保存され、次に開いたときに続きから始まります

## AI

右のノートの内容に指示を付けて AI に送り、応答で右のノートを置き換えられます（Ctrl+Z で戻せます）。

1. AI 欄の「追加」で APIキーを登録します（キー名は自分用の呼び名。例: 個人、仕事）。
   Gemini のキーは [Google AI Studio](https://aistudio.google.com/api-keys) で無料で発行できます。
2. 「指示」を一覧から選ぶか書いて、「実行 ▶」（Ctrl+Enter）。
3. 応答を確かめて「右ノートに反映」。

- 指示は「保存…」で名前を付けて保存し、一覧から選んで使い回せます。
- APIキーは複数登録して「キー」で切り替えられます。モデルはキーごとに覚えます。
- 「一覧」で、そのキーで使えるモデルの一覧を取得できます。

## 他の端末との同期

上の「☁ 同期」から、GitHub の非公開の Gist を使って、歌詞（左右のノート）と指示の一覧を
端末どうしで同期できます。PC で途中まで編集して、iPhone で続きを、といった使い方ができます。

1. [GitHub のトークン作成画面](https://github.com/settings/tokens/new?scopes=gist&description=Lyricker)で、
   「gist」の権限だけのトークンを作る
2. 同期したい各端末で「☁ 同期」を開き、そのトークンを貼り付けて「保存して同期」
   （同じトークンで構いません。最初の端末が同期用の Gist を作り、2 台目からはそれを使います）

- 編集すると数秒後に自動で送られ、画面を開いたとき・戻ったとき・1 分ごとに他の端末の変更を読み込みます。
- 両方の端末で同時に編集した場合は、どちらを残すか選ぶ画面が出ます。
- 同期の画面に「同期先 Gist」の番号が出ます。端末どうしで同じ番号なら、同じ所に同期しています。
- **APIキーは同期しません**（Gist は暗号化されないため）。APIキーは端末ごとに登録してください。

### データの置き場所

歌詞・APIキー・指示の一覧・同期用のトークンは、その端末のブラウザの中（localStorage）に保存されます。
同期を使うと、歌詞と指示の一覧だけが、あなたの GitHub アカウントの非公開の Gist にも置かれます。
AI への問い合わせは、ブラウザから AI のサービスへ直接送ります。

## 開発

ビルド作業は不要です。ファイルをそのまま Web サーバーに置けば動きます
（GitHub Pages ならリポジトリの設定で公開するだけ）。

ローカルで試すときは、`file://` ではなく何かの Web サーバー経由で開いてください
（JavaScript のモジュールとオフライン用の仕組みが `http://localhost` か `https://` でしか動かないため）。

| ファイル | 役割 |
|---|---|
| `index.html` / `app.css` | 画面 |
| `js/app.js` | 画面の動き全体 |
| `js/diff.js` | 左右の行の対応・行頭の印・再出行の判定 |
| `js/ai.js` | AI の共通の窓口（登録の仕組み） |
| `js/gemini.js` | Gemini |
| `js/prompts.js` | 指示の一覧 |
| `js/store.js` | ブラウザ内への保存 |
| `js/cloud.js` | 他の端末との同期（GitHub の Gist） |
| `sw.js` / `manifest.webmanifest` | オフラインで開く・ホーム画面に追加する |

### AI を追加するには

`js/gemini.js` を見本に、`js/ai.js` の先頭に書いた形のオブジェクトを作って `registerProvider` し、
`js/app.js` の先頭で `import './新しいファイル.js';` を足します。`sw.js` の `ASSETS` にもファイルを足してください。
画面の「AI」の一覧に自動で並びます。

ファイルを変えて公開し直したときは、`sw.js` の `CACHE` の番号（`lyricker-v1`）を上げると、
各端末が新しいファイルを確実に取り直します。
