# Lyricker（Web 版）

歌詞の元の内容と編集中の内容を見比べながら推敲するためのノートです。
ブラウザで動くので、Windows・Mac・iPhone・iPad のどれでも同じように使えます。

## 使い方

1. 左のノート（元の歌詞）に歌詞を貼り付けます。右のノートにも同じ内容が読み込まれます。
   - スマートフォンは枠を長押しして「ペースト」、または「貼り付け」ボタン
2. 右のノートで編集します。左と比べて
   - ✓（緑）変更した行 / ＋（緑）追加した行 … 右のノートの行頭
   - −（赤）右で削除した行 … 左のノートの行頭
   - 右のノートで同じ行が 2 回以上出てくる行は橙色（`[サビ]` のように `[ ]` で囲んだ部分は判定しません）
3. 仕上がったら「全文コピー」で右のノートの全文をコピーして、Suno などに貼り付けます。
4. 次の歌詞に移るときは「クリア」（確認のあと左右とも消えます。曲を開いていれば、その曲も閉じます）。

iPhone などを縦向きにすると、編集する右のノートが表示されます（左のノートは上のタブで切り替え）。横向きでは左右に並びます。

そのほか

- 「行を戻す」… カーソル行（選択していれば選択した行）を元の歌詞に戻す。直前で削除した行も戻る
- 「全体を戻す」… 右のノートを元の歌詞に戻す（どちらも Ctrl+Z で取り消せます）
- 「全文ペースト」… 確認してから、右のノートの全体をクリップボードの内容で置き換える（Ctrl+Z で取り消せます）
- 「行を右へ」（左のノートの上）… 左のカーソル行を、右のノートの対応する行にコピーする（上書き）。
  左の行をクリック（タップ）するとその行がカーソル行になります。右で消した行（−）なら、右の同じ位置に差し込みます
- 左右のノートの行頭には、その行を歌うときの音の数（拍）が出ます。
  漢字は文脈から読みを決めてひらがなにしてから数えます。「きゃ」のような小さい字はまとめて 1 拍、「っ」「ん」「ー」は 1 拍。
  英語はおおよその音節の数。数は位取りして読み（2026 → にせんにじゅうろく）、
  1人（ひとり）・3日（みっか）・20歳（はたち）のように読みが変わるものもそのとおりに数えます。空の行と [Verse] のような見出しの行には出ません。
  当て字（本気＝まじ、運命＝さだめ など）は辞書どおりの読みで数えます。
  初めて開いたときに読みの辞書（約 17MB）を取り込みます（2 回目からは端末に保存したものを使います）。
  取り込めなかったときは行頭は空のままです（行番号は出しません）
- 右のノートの行頭（音の数）をクリック（タップ）すると、行頭の色が 赤 → 黄 → 緑 → 元に戻る、と変わります
  （気になる行・保留の行・仕上がった行の目印などに。行を足したり消したりしても、その行に付いていきます）
- 右のノートの文字をダブルクリックすると、その 1 文字を目印として赤く反転表示（もう一度で解除）
- ▲▼（F3 / Shift+F3）で前後の差異へ移動、A− / A＋ で文字の大きさ
- 作業中の内容はブラウザの中に自動で保存され、次に開いたときに続きから始まります

## 曲を聴きながら推敲する

Suno の曲をダウンロードして開くと、歌詞を見ながら Lyricker の中で再生できます（非公開の曲もそのまま使えます）。

1. Suno で曲の「…」→「Download」→「MP3 Audio」で、曲を端末に保存します（iPhone は「ファイル」アプリに保存）。
2. Lyricker の上の「♪ 曲を開く」で、その曲を選びます。
3. 上に出る帯で ▶（再生）／❚❚（一時停止）、■（停止して最初へ）、−5秒 / ＋5秒、つまみで位置を動かせます。

- パソコンでは **F2** で再生・一時停止、**Shift+F2** で 5 秒戻します（歌詞を打ちながら使えます）。
- iPhone ではロック画面やイヤホンのボタンからも操作できます。画面をロックしても再生は止まりません
  （iOS 16.4 以降。消音スイッチが入っていても鳴ります）。
- 曲はこの端末の中で読むだけで、どこにも送りません。最後に開いた 1 曲と再生位置は端末の中に残るので、
  開き直しても続きから聴けます（他の端末とは同期しません）。帯の × で曲を閉じると消えます。

## AI（現在は使用を停止中）

無償で使える AI（Gemini の無償枠）は応答が遅すぎて実用にならないため、AI の機能は画面から隠しています。
仕組みはそのまま残してあり、`js/app.js` の `AI_ENABLED` を `true` にすると元どおり使えます
（AI 関連の画面は `index.html` の `#aiPanel` にまとめてあります）。以下は使うときの説明です。

右のノートの内容に指示を付けて AI に送り、応答で右のノートを置き換えられます（Ctrl+Z で戻せます）。

1. AI 欄の「追加」で APIキーを登録します（キー名は自分用の呼び名。例: 個人、仕事）。
   Gemini のキーは [Google AI Studio](https://aistudio.google.com/api-keys) で無料で発行できます。
2. 「指示」を一覧から選ぶか書いて、「実行 ▶」（Ctrl+Enter）。
3. 応答を確かめて「右ノートに反映」。

- 指示は「保存…」で名前を付けて保存し、一覧から選んで使い回せます。
- APIキーは複数登録して「キー」で切り替えられます。モデルはキーごとに覚えます。
- 「一覧」で、そのキーで使えるモデルの一覧を取得できます。

## 他の端末との同期

上の「☁ 同期」から、GitHub の非公開の Gist を使って、歌詞（左右のノート）と指示の一覧を
端末どうしで同期できます。PC で途中まで編集して、iPhone で続きを、といった使い方ができます。

1. [GitHub のトークン作成画面](https://github.com/settings/tokens/new?scopes=gist&description=Lyricker)で、
   「gist」の権限だけのトークンを作る
2. 同期したい各端末で「☁ 同期」を開き、そのトークンを貼り付けて「保存して同期」
   （同じトークンで構いません。最初の端末が同期用の Gist を作り、2 台目からはそれを使います）

- 編集すると数秒後に自動で送られ、画面を開いたとき・戻ったとき・1 分ごとに他の端末の変更を読み込みます。
- 両方の端末で同時に編集した場合は、どちらを残すか選ぶ画面が出ます。
- 同期の画面に「同期先 Gist」の番号が出ます。端末どうしで同じ番号なら、同じ所に同期しています。
- **AI の APIキーも同期します**。Gist は URL を知っていれば読めてしまうので、キーはトークンから作った鍵で
  暗号化して置きます（トークンを登録した端末だけが読めます）。新しい端末ではトークンを入れるだけで AI も使えます。
  キーの一覧は丸ごと置き換えず、キーの名前ごとに新しく追加・変更・削除した方を残して合わせます。
- 同期する端末には、すべて同じトークンを登録してください（トークンを作り直したら、全端末で入れ直す）。

### データの置き場所

歌詞・APIキー・指示の一覧・同期用のトークンは、その端末のブラウザの中（localStorage）に保存されます。
同期を使うと、歌詞と指示の一覧だけが、あなたの GitHub アカウントの非公開の Gist にも置かれます。
AI への問い合わせは、ブラウザから AI のサービスへ直接送ります。

## 開発

ビルド作業は不要です。ファイルをそのまま Web サーバーに置けば動きます
（GitHub Pages ならリポジトリの設定で公開するだけ）。

ローカルで試すときは、`file://` ではなく何かの Web サーバー経由で開いてください
（JavaScript のモジュールとオフライン用の仕組みが `http://localhost` か `https://` でしか動かないため）。

| ファイル | 役割 |
|---|---|
| `index.html` / `app.css` | 画面 |
| `js/app.js` | 画面の動き全体 |
| `js/diff.js` | 左右の行の対応・行頭の印・再出行の判定 |
| `js/ai.js` | AI の共通の窓口（登録の仕組み） |
| `js/gemini.js` | Gemini |
| `js/prompts.js` | 指示の一覧 |
| `js/store.js` | ブラウザ内への保存 |
| `js/cloud.js` | 他の端末との同期（GitHub の Gist） |
| `js/secrets.js` | 同期する APIキーの暗号化と、端末どうしの合わせ方 |
| `js/player.js` | 曲の再生 |
| `js/mora.js` / `js/mora-worker.js` | 左右のノートの行頭に出す音の数（拍）。別スレッドで読みを決めて数える |
| `vendor/kuromoji/` | 形態素解析 [kuromoji.js](https://github.com/takuyaa/kuromoji.js) 0.1.2 と IPA 辞書（Apache License 2.0。辞書の著作権表示は `NOTICE.md`）。サーバーが gzip を解いて返しても読めるよう、辞書の読み込みに 1 か所手を入れてある |
| `sw.js` / `manifest.webmanifest` | オフラインで開く・ホーム画面に追加する |

### AI を追加するには

`js/gemini.js` を見本に、`js/ai.js` の先頭に書いた形のオブジェクトを作って `registerProvider` し、
`js/app.js` の先頭で `import './新しいファイル.js';` を足します。`sw.js` の `ASSETS` にもファイルを足してください。
画面の「AI」の一覧に自動で並びます。

ファイルを変えて公開し直したときは、`sw.js` の `CACHE` の番号（`lyricker-v1`）を上げると、
各端末が新しいファイルを確実に取り直します。
